**Pertineo** is an AI Career Consulting Platform that analyzes applicants' personal statements, portfolios, and video data to evaluate three-axis competency: **Learning Ability (X) · Job Fit (Y) · Execution Capability (Z)**. Built in collaboration with the **KHU Career Center**, it provides an AI agent that benchmarks users against a database of successful applicants' resumes.

**🎯 Impact**
- 🥇 **Grand Prize (1st)** — KHU Valley Program Startup Camp
- 👥 **1000+ active users** acquired
- 🚀 Live at **[pertineo.khu.ac.kr](https://pertineo.khu.ac.kr/)**
